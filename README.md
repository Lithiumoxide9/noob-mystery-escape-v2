# A Little Escape — Noob's Mystery Trip

A complete, mobile-friendly GitHub Pages website. No framework or build process required.

## Publish on GitHub Pages

1. Sign in at GitHub and create a **new public repository** (example name: `noob-mystery-escape`).
2. Upload **all the contents of this folder**, including `index.html`, `reveal.html`, `script.js`, `styles.css` and `assets/`. Keep the folder structure. The `index.html` file must be at the **repository root**.
3. In the repository, go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**; choose `main` and `/(root)`, then **Save**.
5. The invitation will be available at `https://YOUR-USERNAME.github.io/noob-mystery-escape/`. If you choose a different repository name, replace the last part accordingly.

## Share the surprise safely

- **Send Noob only the main invitation URL** (ending in `/`).
- **Keep the reveal link to yourself until the actual reveal**: `https://YOUR-USERNAME.github.io/noob-mystery-escape/reveal.html`.
- When you're ready, hand Noob your phone with the reveal page open, or send her that second URL. She taps **Open the surprise** to see **Langkawi** and the flight from Penang at **1:30 PM**.
- Do not share `reveal.html` early. Because GitHub Pages is a public static site, **this is a surprise, not a secure lock**: someone who guesses the URL or browses the public repository can see the destination. The main invitation itself does not link to or mention `reveal.html`.

## Features

- Tropical mobile invitation and mystery theme
- Countdown to **31 Oct 2026, 9:30 AM (Malaysia time, UTC+8)**
- Tickable packing checklist saved locally in each browser
- Playful pickup, car, and Instagram photography reminders
- Optional expanded invitation card artwork
- Mission briefing welcome screen (session-based)
- Exclusive Instagram photographer VIP package and fake driver duties
- Spoiler-free mystery itinerary and date-sensitive Noob bulletin
- Secret five-tap easter egg on the word “Noob”
- Separate animated destination reveal page

## Customize

- Edit `index.html` to change wording, reminders or checklist items.
- Edit `reveal.html` to change destination or departure flight details.
- Edit `script.js` to change the countdown date/time.
- Update `assets/invitation-art.webp` if you want a different card.

### Travel note

NRIC may work for a Malaysian citizen on a domestic Malaysia flight; the traveler must bring identification accepted by the booked airline. Verify document requirements for the traveler's nationality and booking.
